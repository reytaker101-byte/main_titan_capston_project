# 2. Images to Artifact Registry

## Objective
Build Docker images in GitHub Actions and push them to Google Artifact Registry using the verified WIF authentication.

## Flow
GitHub repository
-> GitHub Actions
-> Docker build
-> Artifact Registry authentication
-> Docker push
-> Artifact Registry

## Artifact Registry
- Repository: main-titan-capston-project-artifactory-repo
- Location: asia-southeast1
- Format: Docker

## Services
- catalog-service
- cart-service
- order-service
- payment-service

## Implementation
1. Checkout repository.
2. Authenticate to GCP using existing WIF.
3. Authenticate Docker to Artifact Registry.
4. Build service image(s).
5. Tag image with release/version.
6. Push image to Artifact Registry.
7. Verify image exists.
