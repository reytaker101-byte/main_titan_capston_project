# Productionization Checklist

Before calling the system production-ready, implement and test:

- Azure AKS
- ACR
- Key Vault
- Workload Identity
- GitHub OIDC
- private networking
- SSO
- centralized audit
- persistent agent state
- durable queue
- model failover
- prompt/version management
- rate limiting
- token/cost budgets
- image signing/scanning
- dependency/security scanning
- DR and backup
- load testing
- chaos testing
- approval service
- real Slack/PagerDuty/ticketing integrations
- production-grade Prometheus/Grafana
- Argo progressive delivery
