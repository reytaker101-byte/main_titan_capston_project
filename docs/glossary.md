# Beginner Glossary

Agent = software that observes context, decides and can use tools.

LLM = language model used for generation/reasoning.

Tool = controlled function available to an agent.

State = shared structured workflow data.

RAG = retrieval-augmented generation.

Embedding = numerical representation used for semantic similarity.

Vector database = store/search system for embeddings.

Hybrid search = semantic + keyword retrieval.

Multi-agent = multiple specialized agents collaborating.

MCP = model/tool interoperability protocol.

A2A = agent-to-agent communication contract.

GitOps = Git stores desired state and a controller reconciles it.

Argo CD = Kubernetes GitOps controller.

Blue-green = two deployable slots; traffic points to one active slot.

Rollback = return traffic/application to a known-good version.

Remediation = action to restore service.

RCA = root cause analysis.

SLI = measured reliability indicator.

SLO = reliability target.

Error budget = allowed unreliability implied by SLO.

RBAC = role-based permissions.

Policy-as-code = executable safety rules.

Human-in-the-loop = human approval is part of the control flow.

Groundedness = answer supported by evidence.

Evaluation = measurable tests of AI behavior.

Fine-tuning = adapting model weights with curated examples.

Chaos engineering = controlled failure experiments.
